프로젝트 명

Talk-to-Fab: 자연어로 운영하는 디지털트윈 FAB

배경 및 문제 정의
현재 상황 (As-Is): FAB 운영(로트 투입, 디스패칭, 설비 상태 관리, PM, 홀드/릴리즈, 반송)은 복잡한 시스템 화면과 룰 기반 로직을 통해 수행되며, 운영 정책 변경 시 룰 수정과 시스템 반영에 시간이 걸림
Pain Point:
시간: "핫랏 우선 처리", "특정 설비 부하 제한" 같은 운영 의도를 시스템에 반영하기까지 여러 단계 필요
비용: 룰 변경마다 개발·검증 공수 발생
품질: 정책 변경의 영향을 사전에 확인하기 어려워 반영 후 문제가 드러남
기회 요인:
LLM으로 자연어 지시를 구조화된 정책·제약으로 변환 가능
초고속 판단 모델(Jev)로 이벤트 단위 판단을 실시간으로 대량 처리 가능
디지털트윈으로 정책 반영 전 결과를 시뮬레이션해 안전하게 검증 가능
목표 사용자 (Target User)
FAB 운영 담당자: 생산 우선순위와 설비 운영 정책을 결정하는 인력
생산 관리자: 처리량·사이클타임 목표를 관리하며 What-if 분석이 필요한 의사결정자
프로젝트 목표
정성적 목표
목표 1: 자연어 지시만으로 FAB 운영 정책을 즉시 반영하는 인터페이스 구현
목표 2: 지시 반영 전 디지털트윈 시뮬레이션으로 영향을 미리 확인하는 의사결정 지원
목표 3: LLM(정책 해석) + Jev(실시간 판단) 하이브리드 구조의 FAB 운영 적용 실증
정량적 목표 (KPI)
성과 지표	목표 수치	측정 방법	현재 수준
지시 반영 시간	1분 이내	자연어 지시 입력부터 트윈 내 정책 적용까지 시간	룰 수정 방식 기준 측정 예정
지시 해석 정확도	90% 이상	지시 테스트셋 대비 올바른 정책 변환 비율	측정 예정
사이클타임·처리량	룰 기반 디스패처 대비 개선	동일 시나리오 시뮬레이션 비교	룰 기반 베이스라인 측정 예정
위험 지시 차단율	95% 이상	위험 지시 테스트셋 중 확인 요청·차단 비율	측정 예정
핵심 기능 정의
디지털트윈 FAB: 이산사건 시뮬레이션 기반 목업 FAB(설비, 로트, 레시피, OHT, 스토커)와 웹 UI. 아이소메트릭 맵 위로 로트·OHT 흐름을 실시간 시각화
자연어 운영 엔진: LLM이 자연어 지시를 타입이 정해진 정책·제약으로 변환하고, Jev가 해당 정책에 따라 디스패칭·반송·홀드/릴리즈 판단을 이벤트마다 실시간 수행. 확신도가 낮은 판단은 LLM으로 에스컬레이션하며 UI에 시각화
What-if 시뮬레이션 및 안전장치: 지시를 실제 반영하기 전 트윈에서 미리 실행해 KPI 변화를 비교 제시하고 승인 후 반영. 위험 지시는 확인 요청. 설비 다운·핫랏 투입 등 장애 시나리오 주입 기능 제공
기대 효과
업무 효율화: 운영 정책 반영 시간을 룰 수정 방식 대비 대폭 단축
품질 향상: 사전 시뮬레이션으로 정책 변경에 따른 부작용 예방, 지시 해석 정확도 90% 이상
비용 절감: 정책 변경에 따른 개발·검증 공수 감소, 실시간 판단의 LLM 의존도 축소로 추론 비용 절감
범위 및 제약사항
In Scope: 목업 FAB 디지털트윈 구축, 자연어 지시 기반 운영(로트 투입·추적, 디스패칭, 설비 상태, PM, 홀드/릴리즈, 반송), What-if 시뮬레이션, 웹 UI
Out of Scope: 실제 FAB 설비·MES 연동, 실데이터 기반 운영, 공정 물리 시뮬레이션
제약사항: 사내 실데이터 사용 불가로 목업 데이터 기반 구축(현실성은 도메인 경험 기반 설계로 보완), Jev 외부 API 반입 정책 확인 필요(대안: SemIf), 시뮬레이션 결과의 실제 FAB 적용 가능성은 별도 검증 필요
