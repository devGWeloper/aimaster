### 프로젝트 명

Persona Swarm: 가상 사용자 에이전트 군단 기반 AI 에이전트 자동 검증 시스템

### 배경 및 문제 정의

* 현재 상황 (As-Is): AI 에이전트 테스트가 개발자가 직접 작성한 소수의 시나리오에 의존하며, 실제 사용자의 다양한 표현·숙련도·모호한 요청은 운영 후에야 발견됨

* Pain Point:
  * 시간: 테스트 시나리오 작성과 수동 검증에 많은 공수 소요
  * 비용: 운영 중 발견된 결함 대응 비용이 개발 단계 대비 큼
  * 품질: 같은 요청도 실행마다 결과가 달라지는 비일관성이 단발성 테스트로는 드러나지 않음

* 기회 요인:
  * 2026년 9월 IBM Research가 에이전트를 과제당 5회 실행 시 실행 성공률 77.4%와 달리 5회 모두 성공한 과제는 53.0%에 그친다는 "일관성 격차"를 발표하며 반복·다양성 기반 테스트의 필요성이 부각됨
  * LLM 기반 시뮬레이션 사용자 에이전트로 멀티턴 대화와 요구사항 변경까지 재현 가능해짐

### 목표 사용자 (Target User)

* AI 에이전트 개발자: 배포 전 에이전트 품질을 검증해야 하는 엔지니어
* QA 담당자: 에이전트 서비스의 결함 발굴과 회귀 테스트를 담당하는 인력

### 프로젝트 목표

* 정성적 목표

  * 목표 1: 다양한 사용자 유형을 재현하는 가상 사용자 에이전트 자동 생성

  * 목표 2: 테스트 시나리오 작성·실행·결함 분류의 전 과정 자동화

  * 목표 3: 에이전트 품질 평가 기준을 단발 성공률에서 반복 일관성(pass^k) 중심으로 고도화

* 정량적 목표 (KPI)

| **성과 지표** | **목표 수치** | **측정 방법** | **현재 수준** |
| --- | --- | --- | --- |
| 발견 결함 수 | 수동 테스트 대비 3배 이상 | 동일 기간·대상 에이전트 기준 발견 결함 비교 | 수동 테스트 베이스라인 측정 예정 |
| 실패 유형 커버리지 | 사전 정의 실패 유형의 80% 이상 | 실패 분류 체계 대비 탐지된 유형 비율 | 측정 예정 |
| 테스트 작성 공수 | 70% 감소 | 시나리오 작성·실행 소요 시간 비교 | 수동 작성 |
| 일관성 지표(pass^5) | 측정 체계 구축 및 개선 추적 | 동일 과제 5회 반복 실행 시 전부 성공 비율 | 미측정 |

### 핵심 기능 정의

1. 페르소나 생성기: 직무, 숙련도, 말투, 성격(급함·모호함·공격적 등)을 조합해 가상 사용자 에이전트를 자동 생성

2. 군단 실행 엔진: 다수 페르소나가 동시에 멀티턴 대화로 요청을 수행하고, 중간에 요구사항을 바꾸거나 모호하게 말하는 등 실제 사용 패턴을 재현

3. 자동 채점 및 결함 리포트: Jev 기반 실시간 응답 채점, 실패 유형 자동 분류, 반복 실행 일관성 분석 리포트 생성. 발견된 실패 케이스는 회귀 테스트셋으로 자동 편입

### 기대 효과

* 업무 효율화: 테스트 시나리오 작성 및 실행 공수 70% 감소

* 품질 향상: 운영 전 결함 발굴률 향상, 실행 간 비일관성 문제의 사전 탐지

* 비용 절감: 운영 단계 결함 대응 비용 감소. 발견된 실패가 1번 프로젝트(Self-Healing Agent)의 진화 재료로 재활용되어 개선 사이클 단축

### 범위 및 제약사항

* In Scope: 페르소나 생성, 멀티턴 시뮬레이션 실행, 자동 채점·분류, 회귀 테스트셋 관리, eWorks Agent 및 3번 프로젝트 대상 적용

* Out of Scope: 실제 사용자 대상 A/B 테스트, 성능 부하 테스트(인프라 레벨)

* 제약사항: 가상 사용자의 현실성 검증 필요(실제 사용 로그와 비교), 대량 시뮬레이션 시 LLM 비용 관리 필요, 채점 모델 자체의 정확도 검증 필요
