### 프로젝트 명

eWorks Self-Healing Hybrid Agent: Jev·LLM 하이브리드 기반 자가 개선형 업무 에이전트

### 배경 및 문제 정의

* 현재 상황 (As-Is): 업무 에이전트가 단순 액션 요청(조회, 분류, 라우팅)부터 복잡한 추론까지 모든 판단을 대형 LLM에 의존하고 있으며, 요청 처리 실패 시 개발자가 로그를 확인하고 프롬프트·툴 코드를 수동으로 수정하는 구조

* Pain Point:
  * 시간: 단순 판단에도 LLM 텍스트 생성 대기로 응답 지연 발생
  * 비용: 전체 요청의 대부분을 차지하는 단순 판단에 고비용 LLM 호출 소모
  * 품질: 실패 원인 분석과 수정이 사람에게 의존해 개선 주기가 길고, 같은 유형의 실패가 반복됨

* 기회 요인:
  * 2026년 9월 텍스트 대신 확률이 붙은 구조화 판단을 반환하는 System One 모델(Jev)이 등장해, 단순 판단을 수십~수백 배 빠르고 저렴하게 처리 가능
  * 같은 달 Google의 RRSI 등 에이전트가 자기 하네스(프롬프트·툴·제어 코드)를 스스로 고쳐 진화하는 Recursive Self-Improvement 연구가 집중적으로 발표되며 실용 단계에 진입

### 목표 사용자 (Target User)

* eWorks Agent 사용자: 사내 업무 시스템에서 반복적인 조회·처리 요청을 수행하는 현업 담당자
* 에이전트 개발·운영자: 에이전트 실패 대응과 품질 개선을 담당하는 AI 엔지니어

### 프로젝트 목표

* 정성적 목표

  * 목표 1: 판단 난이도에 따라 Jev(빠른 판단)와 LLM(복잡한 추론)을 자동 분배하는 하이브리드 처리 구조 확립

  * 목표 2: 실패 발생 시 에이전트가 스스로 원인을 분석하고 코드를 수정·검증하는 자가 복구 체계 구축

  * 목표 3: 최신 System One 모델 및 Recursive Self-Improvement 기술 내재화

* 정량적 목표 (KPI)

| **성과 지표** | **목표 수치** | **측정 방법** | **현재 수준** |
| --- | --- | --- | --- |
| 평균 응답 시간 | 50% 이상 단축 | 동일 테스트셋 기준 요청별 응답시간 측정 | LLM 단독 구조 베이스라인 측정 예정 |
| LLM 호출 비율 | 30% 이하 | 전체 요청 중 LLM 에스컬레이션 비율 | 100% (전량 LLM 처리) |
| 실패 자가 복구율 | 60% 이상 | 실패 케이스 중 사람 개입 없이 수정·검증 통과 비율 | 0% (전량 수동 수정) |
| Held-out 성능 향상 | 진화 전 대비 +10%p | 진화에 사용하지 않은 별도 테스트셋 성공률 비교 | 베이스라인 측정 예정 |

### 핵심 기능 정의

1. 하이브리드 판단 라우터: 사용자 요청을 Jev가 먼저 판단하고, 확신도가 임계값 미만이거나 복잡한 추론이 필요한 경우만 LLM으로 에스컬레이션

2. 실패 분석 및 자가 수정 엔진: 실패한 실행 기록을 분석해 원인을 분류하고, 프롬프트·툴 코드·제어 흐름에 대한 수정안을 자동 생성

3. 정규화된 검증 파이프라인(RRSI): 수정안을 evolve셋과 held-out셋으로 나눠 검증하고, 수정 범위 제한·과적합 탐지를 거쳐 일반화되는 수정만 반영. 모든 변경은 이력 관리 및 롤백 가능

### 기대 효과

* 업무 효율화: 단순 액션 요청 응답 시간 50% 이상 단축

* 품질 향상: 동일 유형 실패 재발 감소, 진화 후 처음 보는 요청에서도 성공률 향상

* 비용 절감: LLM 호출 70% 이상 감소로 추론 비용 절감, 실패 대응 개발 공수 감소

### 범위 및 제약사항

* In Scope: eWorks Agent 내 액션 요청 처리 하이브리드화, 하네스 레벨 자가 수정(프롬프트·툴·제어 코드), 검증 파이프라인 및 변경 이력 관리

* Out of Scope: 모델 가중치 학습·파인튜닝, 운영 환경 코드의 무검증 자동 배포(최종 반영은 승인 절차 유지)

* 제약사항: Jev는 외부 API로 사내망 반입 정책 확인 필요(대안: 오픈소스 SemIf 온프렘 구성), Jev 컨텍스트 32K 토큰 제한, 자가 수정은 샌드박스 환경에서만 수행
